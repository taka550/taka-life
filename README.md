# Taka-Life Ver.2.1.1

ミオ劇場のiPhone表示を改善しました。

- エンジェルミオとデビルミオを画面上部に常時表示
- 吹き出しがキャラクターの顔を隠さない配置へ変更
- スマホ幅で2人が並んで見えるよう調整
- 会話アニメーションと既存データはそのまま維持


## Ver.2.2.0
- 正式版ミオ劇場UI
- キャラクター画像から文字・吹き出しを除去
- 会話はHTML/CSSで描画し、体重データに合わせて変更
- キャラクター付き吹き出しと登場アニメーション

## Ver.2.3.0
- 朝・昼・夕方・夜でミオ劇場の舞台色が変化
- 光の粒がゆっくり漂うアンビエント演出
- 2人の静かな呼吸アニメーション
- 話している人物を明るく、聞いている人物を少し抑える演出
- 吹き出しと締め演出を滑らかに改善

## Ver.3.1.0
- Gemini API接続を追加
- 「ミオに相談」から自由入力でAIミオ劇場を生成
- 最新体重・目標・直近5回・メモをGeminiへ送信
- APIキーはアプリファイルやGitHubに含めず、利用端末のlocalStorageに保存
- 接続テスト機能を追加

### 注意
この版は個人利用・試作用です。ブラウザからGemini APIへ直接接続するため、
一般公開する場合はAPIキーをサーバー側へ移す必要があります。

## Ver.3.1.0
- 固定モデル `gemini-2.5-flash` を廃止
- APIキーで利用可能なモデルを `models.list` から自動取得
- Gemini 3系のFlashモデルを優先して自動選択
- 選択済みモデルが終了した場合は再取得して再試行
- Gemini 3.6以降で非推奨となった `temperature` 指定を削除

## Ver.3.1.0 — AI Mio First Generation

- GeminiモデルをAPIのモデル一覧から自動選択
- モデル終了時にキャッシュを破棄し、自動で再選択
- JSONコードフェンス、前置き、複数パーツ、思考パーツを除外して解析
- 波括弧を文字列内まで考慮したJSON抽出
- 構造化出力が使えないモデルでは通常JSON生成へ自動フォールバック
- 最新体重、BMI、目標との差、直近7回の変化、曜日、時間帯を自動共有
- 最近8回の相談と締め言葉をiPhone内だけに保存し、自然な会話メモとして利用
- APIキーと会話メモはZIP・GitHubには含まれない

### セキュリティ
個人利用の試作構成です。APIキーはlocalStorageに保存され、Gemini APIへの認証にだけ使用します。
一般公開する場合はバックエンド経由へ移行してください。

## Ver.3.1.0
- JSON出力要求を廃止
- DEVIL1 / ANGEL1 / DEVIL2 / ANGEL2 / FINALE の5ラベル方式へ変更
- 日本語ラベル、Markdown記号、見出しと本文の改行にも対応
- ラベルが欠けても5つの文章があれば自動復元
- 読み取り失敗時は形式を念押しして再試行

## Ver.3.1.0
- 接続テストとミオ劇場生成を完全分離
- 接続テストは通常文章が1つ返れば成功
- 接続テストでは5セリフ形式を要求しない
- ミオ劇場生成だけ `DEVIL1 / ANGEL1 / DEVIL2 / ANGEL2 / FINALE` を解析
- 劇場形式エラーでも「接続自体は成功」と分かる表示に改善

## Ver.3.1.0
- AIへ送る履歴を軽量化（体重5件、会話3件）
- 出力文字数を短くして応答速度を改善
- 長いプロンプト例を削除
- 最大再試行回数を削減
- 接続テスト12秒、劇場生成18秒のタイムアウトを追加
- 生成中の経過秒数を画面表示
- タイムアウト時の案内を改善
