# Taka-Life Ver.2.5.1

体重記録とAIミオ劇場を備えた、iPhone向けPWAです。

## Ver.2.5.1 の変更点

- Geminiの固定ラベル形式を廃止
- デビルミオとエンジェルミオを別プロンプトで生成
- 2つの生成を並列実行し、待ち時間を抑制
- 自然文をアプリ側で安全に劇場形式へ整形
- Gemini通信、タイムアウト、エラー処理を共通化
- 利用可能な文章生成モデルを自動選択
- 接続テストとミオ劇場生成を分離
- APIキーはブラウザのlocalStorageにのみ保存
- アプリ表示・Service WorkerキャッシュをVer.2.5.1へ更新

## ファイル

- `index.html`：画面
- `styles.css`：デザイン
- `app.js`：体重管理、AIミオ、PWA更新処理
- `sw.js`：オフラインキャッシュと更新
- `manifest.webmanifest`：PWA設定

## APIキーについて

APIキーはZIPやGitHubには含まれません。アプリ画面で入力したキーは、その端末のブラウザ内に保存されます。公開運用では、将来的にバックエンド経由へ移行することを推奨します。


## Ver.2.5.1 の改善
- 接続テストは返答内容に左右されず「接続できました」と表示
- 5つの吹き出しをそれぞれ独立した一文として並列生成
- 長文の機械的な文章分割を廃止
- 各吹き出しの役割を明確化し、途中で切れた文章を防止
- 返答の余計な引用符・話者名・複数文を自動整形
