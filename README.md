# Taka-Life Ver.2.6.5

体重記録とAIミオ劇場を備えた、iPhone向けPWAです。

## Ver.2.6.5 の変更点

- タカの基本プロフィールを短く整理し、Geminiへ毎回渡す仕組みを追加
- ミオ劇場の相談履歴を端末内に最大30件保存
- 旧形式の会話メモを新しい記憶形式へ自動移行
- 健康・仕事・家族・スタバ・読書・食事・運動・気分・アプリのタグを自動付与
- 今回の相談に関係する記憶を最大5件だけ抽出
- 関連記憶は1〜2点を自然に使い、無関係な情報を無理に混ぜないよう調整
- デビルミオとエンジェルミオの会話連続性、具体性、ユーモアを強化
- 一般論や定型的な健康助言に偏らないプロンプトへ改善
- Gemini利用回数の目安を、太平洋時間0時基準で自動リセット
- Geminiへの生成リクエストは1回のまま維持

## 記憶の仕組み

Gemini API自体に長期記憶を持たせるのではなく、Taka-Lifeが端末内のlocalStorageに会話メモを保存します。相談時には、キーワード・タグ・新しさから関連度を計算し、必要なメモだけをGeminiへ渡します。

## ファイル

- `index.html`：画面
- `styles.css`：デザイン
- `app.js`：体重管理、AIミオ、記憶検索、PWA更新処理
- `sw.js`：オフラインキャッシュと更新
- `manifest.webmanifest`：PWA設定

## APIキーについて

APIキーはZIPやGitHubには含まれません。アプリ画面で入力したキーは、その端末のブラウザ内にのみ保存されます。公開運用では、将来的にCloudflare Workersなどのバックエンド経由へ移行することを推奨します。

## 利用回数について

画面の20回はアプリ内で数えた目安であり、Googleが公開する実際の残量ではありません。リセット基準はGemini APIの日次枠に合わせて太平洋時間0時としています。
