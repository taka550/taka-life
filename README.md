# Taka-Life Ver.2.7.2

体重記録とAIミオ劇場を備えた、iPhone向けPWAです。

## Ver.2.7.2 の変更点

- 「記録して、ミオ劇場へ」で体重を先に確実に保存し、その記録を主役にGemini版ミオ劇場を生成
- 生成成功時はミオ劇場へ自動スクロールし、既存のアニメーションで掛け合いを再生
- Geminiの利用目安上限、実際の429制限、APIキー未設定、通信失敗時も体重記録は保持
- Geminiを利用できない場合はエラーで記録を巻き戻さず、「情報更新だけ」の正常な代替動作に変更
- アプリ表示、キャッシュ、静的ファイル参照のバージョンを2.7.2へ統一

## Ver.2.7.0 の変更点

- Geminiの構造化出力（JSON Schema）を使用し、7つのセリフを安定して受け取る方式へ変更
- 区切り見出しと `===END===` への依存を廃止
- Gemini 3系では思考レベルをLOW、Gemini 2.5 Flash系では思考を停止し、セリフ用の出力枠を確保
- 出力上限を2048トークンに設定し、画面側は全文表示を維持
- エンジェル1を会話全体の軸とし、各ターンが「エンジェル1＋直前の相手」を参照するルールを維持
- Geminiが上限で終了した場合と、返答形式が崩れた場合のエラーを区別

## これまでの内容

- ミオ劇場を4ターンから6ターンの「一続きの短いコント」へ変更
- デビルミオを「タカを誘惑するボケ担当」として正式定義
- エンジェルミオを「デビルへのツッコミ・現実確認・応援担当」として正式定義
- 二人は敵ではなく、どちらもタカの味方で仲良しという世界観を追加
- デビル1 → エンジェル1 → デビル2 → エンジェル2 → デビル3 → エンジェル3の会話構造を固定
- 各ターンが直前のセリフへ必ず返答し、途中で話題を変えないようプロンプトを強化
- 食べ物、スタバ、体重、マンジャロ・体調、仕事、読書、疲れの話題別リアクション指針を追加
- 「保健室の先生」「一般論」「同じ定型句」「危険な誘惑」を明確に禁止
- 生成前の自己チェックとして、会話連続性・誘惑とボケ・具体的なツッコミ・タカ専用感・前向きな締めを指定
- 6ターン表示に合わせて劇場アニメーションを自動処理方式へ変更
- Geminiへの生成リクエストは1回のまま維持

## ミオ劇場の役割

### デビルミオ
タカを誘惑するボケ担当です。軽い関西弁で欲望や言い訳を代弁しますが、本当に危険なことは勧めません。

### エンジェルミオ
デビルへのツッコミ、現実確認、タカの応援担当です。説教ではなく、今日できる具体的な一歩へ着地させます。

## 記憶の仕組み

Gemini API自体に長期記憶を持たせるのではなく、Taka-Lifeが端末内のlocalStorageに会話メモを保存します。相談時には、キーワード・タグ・新しさから関連度を計算し、必要なメモだけをGeminiへ渡します。

## APIキーについて

APIキーはZIPやGitHubには含まれません。アプリ画面で入力したキーは、その端末のブラウザ内にのみ保存されます。公開運用では、将来的にCloudflare Workersなどのバックエンド経由へ移行することを推奨します。

## 利用回数について

画面の20回はアプリ内で数えた目安であり、Googleが公開する実際の残量ではありません。リセット基準はGemini APIの日次枠に合わせて太平洋時間0時としています。
